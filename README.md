# web-image-archive · v1.0.0

面向 Codex 的网页图片归档技能：可以自动抓取网页的图片，适用于批量导出网站上的图片，识别原图与页面大图，历史及跨作品查重，下载后完整解码验证，存入本地或者导入 Eagle。

## 使用

将本仓库作为 `web-image-archive` 技能目录安装到你的技能位置，或直接引用根目录的 [SKILL.md](SKILL.md)。自动发现策略保持默认开启。

示例：使用 `$web-image-archive`，从我指定的 10 个收藏作品链接中保存全部图片，按作品分组，检查历史重复，并导入我指定的 Eagle 库。

下载目录、浏览器会话、运行时与缓存、历史清单、批次数量和 Eagle 库均由任务配置指定。不要上传你的登录信息、签名下载 URL、私人清单或采集图片到这个技能仓库。

## 已验证范围

- Boardmix：通过原始资源与缩略图映射取得 original（原图），按尺寸、字节数与已确认的来源 MD5 核验；实际验证过 25 张原图。
- ArtStation：从已登录收藏页读取 10 个作品，共 95 张作品页面大图，复用已有首图，按作品分组；全部通过完整解码、去重及 Eagle 库内文件核验。
- Eagle：本机官方 API、库路径确认、按作品子分类、异步完成确认与库内 SHA256 核验。

站点内部接口与页面结构会变化，技能要求现场核对。它不是免登录或绕过付费下载的工具。

## 辅助脚本

- `scripts/extract_artstation_images.js`：通过浏览器支持的只读 evaluate 提取当前作品图片；须先加载完整目标作品内容。
- `scripts/verify_images.py <批次目录>`：读取 `download-manifest.json`，解码并核验文件；需要 Python 3.9+ 和 Pillow。依赖安装位置遵守你的磁盘约束。输出 JSON 到标准输出，不改写原文件或清单。

技能的完整配置与站点说明见 [references](references)。
