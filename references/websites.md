# 普通网页与 ArtStation 适配

## 发现资源

先确认用户要单个作品、艺术家公开作品列表还是指定链接集合。对列表按站点实际分页或滚动机制收集，记录作品稳定 ID 与 canonical URL。达到指定数量即可停止，不默认穷尽整个账户。

从当前页面实际可见或已加载的内容寻找：

- 作品图片、picture/source/srcset 和懒加载字段。
- 图片查看器的下载原图入口、明确的 original/download 链接。
- 页面结构化作品数据中与该作品对应的附件及尺寸字段。
- 该页实际调用的作品资源接口。优先查官方说明或现场观察，不猜隐藏端点。

排除头像、图标、封面占位图、广告和无关推荐。一个作品可能包含多张图、视频、3D 或嵌入内容：仅下载用户范围内的图片，其他类型记录为未纳入，不用视频截图替代。

## 质量判定

srcset 最大项只证明响应式候选中最大，不证明是上传原件。图像宽度大、URL 包含 original 或文件名不带 thumb 均不足以单独认证。

优先证据：站点原生下载操作、作品附件元数据明确列出的 original 与 thumbnail 关系、原始尺寸/字节数/已知校验和。不要盲目删除查询参数或把 small 替换为 original；签名、转换、权限参数可能因此失效。

只有最高分辨率公开预览时，交付标记为 `best_available`；用户只接受原图时明确阻碍，不能降级后声称任务完成。

## ArtStation 状态

已实测：复用用户已登录的 Chrome 收藏页，收集目标作品链接，逐作品读取实际渲染的图片。当前页面的 `picture img.img-fit` 对应作品图片，`source[srcset]` 提供 small/medium/large 响应式版本；不应把侧栏推荐或收藏缩略图纳入作品。选择器和页面结构仍需现场核对。

收藏页导航通知中也可能含 `/artwork/` 链接。不能对全页 artwork 链接直接取前 N 项；限定收藏网格，或核验链接确实来自可见收藏项，排除 notification_id 等通知入口。逐链接保存全部作品图片，不只保存第一张。

实际验证的交付为页面 large 大图，不能证明是上传原件，质量标记 best_available。不要将 large 擅自替换为 original。记录艺术家、作品标题和来源页，遵守可访问范围。原图与商店付费下载并非同一授权，不推断可下载未授权资产。

## 浏览器准备

复用已授权登录会话。独立浏览器应显式设置运行路径、profile、cache、TEMP/TMP、downloads 和会话目录。使用已有浏览器连接时核实启动路径设置是否真的生效；连接模式可能忽略 profile 参数。不要为了修复连接不断启动同一 profile，先检查是否已有浏览器占用以及当前连接端口。
